# Запуск программы BCC

**Запускайте START.bat** — это запуск Modern Qt, независимо от Codex и Ollama.
Первый запуск автоматически подготавливает отдельное окружение Python.
При ошибке откройте START_DIAGNOSTIC.bat для вывода исключения и журнала.
AI_CYCLE_WINDOWS.bat — **не запуск программы**, а необязательный инструмент разработки.

# Bot Control Center Pro R5 — проверка переработанного Modern Qt (НЕ РЕЛИЗ)

1. Распакуйте архив **в новую папку**, не поверх рабочего `MY_BOTS` и не поверх предыдущего пакета. Не добавляйте туда свои реальные базы, кошельки и ключи.
2. Запустите `CHECK_WINDOWS.bat`. Он использует отдельное тестовое пространство и запишет `BCC_VALIDATION_RESULTS_*.zip`.
3. В конструкторе Polymarket проверьте вертикальную шкалу из 7 этапов: переключение этапов реально меняет страницу, отметка означает посещение, не торговую проверку.
4. На шаге «Условия входа» проверьте пять вкладок: импульс, ASK, секунды входа, индивидуальные рынки, комиссия. Задайте вход 47,5 сек и проверьте сводку; сохраните и откройте повторно. Для режима «В любое время» расписание должно отображаться как *не действующее*.
5. Проверьте светлую и тёмную темы, окно просмотра действующих параметров, главный Dashboard и группировку рабочих кнопок. Вручную сравните с утверждённым макетом.
6. Пришлите сюда архив `BCC_VALIDATION_RESULTS_*.zip` и снимок конструктора. Этот пакет НЕ содержит пользовательских ботов, не отправляет реальные ордера и не предназначен для LIVE-торговли.

*Составные фильтры RSI/EMA/объёма реализованы начиная с R6.2; по умолчанию для старых конфигураций они выключены. Наличие активного рынка отдельно проверяется перед каждой PAPER-сделкой.*

## Проверка R6.4 — выбор монет

Откройте создание Polymarket → «Монеты и депозит» → «Выбрать / добавить монеты».
Список слева должен **сразу** содержать BTC, ETH, SOL, XRP, DOGE, HYPE и ZEC,
без нажатия на кнопку и без подключения Gamma. Это список поддерживаемых монет,
а не доказательство наличия активного рынка для каждой длительности прямо сейчас.
Выберите SOL, добавьте в бот; BTC и ETH должны сохраниться после нажатия Save.
Проверьте поиск, «Добавить все поддерживаемые», удаление выбранной монеты,
закрытие с Cancel (не меняет конфигурацию) и повторное открытие.

Для VELES проверьте, что после открытия выбора монет загрузка Bybit начинается
автоматически; если API недоступен или ограничил запросы, должен появиться текст
ошибки и возможность повторной загрузки. Существующие выбранные монеты не должны
пропадать. Отчёт `BCC_VALIDATION_RESULTS_*.zip` отправляйте после `CHECK_WINDOWS.bat`.
