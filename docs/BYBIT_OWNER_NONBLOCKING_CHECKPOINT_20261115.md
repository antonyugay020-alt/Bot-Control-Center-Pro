## Common architectural defect and coordinated correction

The financial owner called `source.orderbook(symbol)` synchronously whenever a completed book aged before processing. That full admission reader can wait for risk tiers, marks and a Hub cache miss. Unlike the position reader, it does not carry the full portfolio valuation cohort. While the owner waits, background quotes and the Hub continue receiving data, but no owner transaction updates the remaining held positions. Enough queued completions recreate this delay repeatedly. The previous ten-symbol live probe and in-memory portfolio observer did not traverse this owner handoff, so their PASS was insufficient.

- Aged handoffs now request one background repair through the existing bounded transport dispatchers. Held-exposure repair uses the position lane; scanner repair uses the history/discovery lane. Pending repairs coalesce per symbol, share the existing admission budgets, retain history/funding inputs and avoid duplicate same-cycle quote dispatch. A second stale handoff fails closed; it cannot start an unbounded synchronous owner retry. Stop cancels queued repairs through the same owner lifecycle.
- PublicData exposes an owner-safe cache observation read. It validates the already vetted UTC reference without launching a clock network probe, reads only admitted Hub rows, preserves independent real markPrice and bid/ask evidence, and retains provider-denial fences. It never registers/waits for a new transport request. Custom/non-Bybit transports cannot inherit Bybit valuation evidence through this API.
- The single financial worker commits available fresh portfolio collateral and valuations on a half-second cadence even when every history/quote future is waiting and no trading tick completes. These are ordinary owner SQLite/risk transactions. This observation lane neither executes orders nor fabricates orderbook depth, fees, prices or timestamps. Stop/restart still uses the same persisted account state.
- Immediately before a tick, the owner reads current admitted observations. A missing execution book does not erase independently verified current collateral or valuation. Without such evidence the original failure fences still revoke prices. Expired observations and stale books remain unusable; provider denial blocks an already completed fresh tick before strategy execution. More recent quotes cannot be rolled back by an older completion.
- Owner telemetry now includes cohort commits, deferred refreshes, maximum tick duration and current cohort errors. UI report export records the actual executable fingerprint and source integrity, including safe failure evidence when source files are damaged. Collection still does not stop workers or archive the raw public-cache database.

No market-age threshold, original receipt clock or provider quota was loosened. Financial state is written only by the existing owner, not by a quote thread. Existing explicit missing-book revocation, manual exits, risk, funding, recovery and accounting regressions remain exercised.
