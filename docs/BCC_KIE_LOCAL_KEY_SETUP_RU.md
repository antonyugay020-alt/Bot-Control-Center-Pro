# BCC: безопасный локальный ввод API-ключа Kie.ai

Состояние: **только сохранение ключа, без API-подключения и без платных запросов**. Инструкция относится исключительно к отдельной ветке разработки Bot Control Center Pro.

## Первый запуск на Windows

Создать **один отдельный каталог**. Не использовать каталог с работающими ботами и не выполнять перезагрузку:

    $agent = "$HOME\Desktop\BCC_AGENT_GATEWAY"
    if (Test-Path -LiteralPath $agent) { throw "Каталог уже существует. Не перезаписывайте его." }
    git clone --depth 1 --single-branch --branch agent/bcc-work-claude-gateway-20261117 https://github.com/antonyugay020-alt/Bot-Control-Center-Pro.git "$agent"
    if ($LASTEXITCODE -ne 0) { throw "Git clone не выполнен" }
    & "$agent\BCC_KIE_KEY_WINDOWS.cmd"

Откроется консоль. На запрос **Kie.ai API key (hidden)** вставить ключ прямо в окно (не в чат, не в командную строку, не в GitHub). При вводе символы не отображаются. Нажать Enter; затем повторить ключ и снова нажать Enter.

При успехе: **Key saved to Windows Credential Manager. No API request made.**

Если ключ ранее сохранён, замена требует явного ввода **REPLACE**. Совпадение двух вводов обязательно.

## Проверить сохранение или удалить

В обычном PowerShell (секрет **не передаётся** в аргументах):

    $agent = "$HOME\Desktop\BCC_AGENT_GATEWAY"
    py -3 -I "$agent\tools\bcc_kie_credentials.py" status

Для удаления (потребуется явное слово **DELETE**):

    py -3 -I "$agent\tools\bcc_kie_credentials.py" remove

Если py недоступен, можно использовать python -I с тем же путём. Достаточно Python 3.10+ и стандартной библиотеки; дополнительные пакеты не устанавливаются. Запускать под обычной учётной записью Windows, без администратора.

## Что именно защищается

- Учётные данные сохраняются в **Windows Credential Manager**, Generic Credential: **BCC.DevAgent.KieAI.APIKey.v1**.
- Секрет не передаётся в аргументах командной строки, переменных среды, исходных файлах, GitHub, отчётах и логах утилиты.
- Утилита не содержит HTTP-клиента, не подключается к Kie.ai, не обращается к Graphify, не запускает/останавливает торговые боты и не меняет их базы.
- Как и другие пользовательские секреты Windows, эти учётные данные **доступны программам, запущенным под той же учётной записью пользователя**. Это не защита от заражённого процесса с правами пользователя. Python также не гарантирует немедленную очистку всех копий строки в оперативной памяти.
- Встроенный лимит бюджета из tools/bcc_claude_budget.py — **отдельный автономный прототип**. Наличие сохранённого ключа не означает разрешение тратить деньги.
- Облачный GPT Work **не может автоматически прочитать Windows Credential Manager**. Для дальнейшей совместной работы нужен отдельный локальный агент и проверенный GitHub-маршрут либо совместимое защищённое соединение. Это ещё не реализовано.

## Доказательства и ограничения

- 11 автономных тестов tests/test_bcc_kie_credentials.py прошли на Linux, включая имитацию Win32 CredWrite/CredRead/CredDelete и проверки, что ключ не показывается в ответах.
- SHA трёх файлов, сохранённых на GitHub, совпали с проверенными локальными файлами.
- Реальная Windows-проверка записи в хранилище **пока не выполнялась**. Полный BCC regression, пакетная проверка манифеста, Windows Qt E2E и совместимость API Kie.ai **не подтверждены**.
- Следующий этап — независимый Windows-тест сохранения/наличия ключа без внешнего запроса. Платные вызовы Claude остаются запрещёнными до отдельного разрешения.
