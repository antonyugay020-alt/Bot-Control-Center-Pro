## Coordinated integration

- Held positions and pending exposure have their own bounded background risk-metadata dispatcher. Renewal does not depend on fresh books, history completion or risk-management mode. Foreign depth adapters must explicitly implement risk transport before inheriting this Bybit lane. Original quotas, provider denials, cooldown and leadership fences remain enforced; existing-exposure priority propagates through the request boundary.
- Metadata-only completions return to the sole financial owner through typed ticks. They update tiers independently of WS bid/ask and markPrice, retain original `risk_at`, and cannot execute trades, revoke independently fresh prices on a metadata outage, or satisfy once-mode scanning. Per-symbol metadata errors and completion/error counters remain available. Closed exposure is ignored. Older history/metadata completion cannot overwrite newer risk evidence.
- A worker schedules its next metadata attempt from the actual source age. All three Hub producer modes acknowledge against the actual shared cache residence deadline. An old cached response cannot defer renewal past that deadline or acquire a new exchange timestamp merely by being read. The 240 s metadata cache, 300 s admission gate and 3 s quote/mark gates remain unchanged. No REST price fallback is introduced.
- SQLite internally interns repeated diagnostic reason strings. Reads/reopens restore exactly the public state, without truncation, shared mutable rows or removal of diagnostic details. Legacy documents remain readable; the next atomic transaction converts their internal encoding. Invalid encodings fail before financial mutation. Chart and execution storage stay separate. Key-classification caching stores only immutable key classification; every state/value is still traversed and validated on each financial write.
- On a separate copy of the second native account, the hot SQLite document shrinks from 3,027,093 to 1,381,238 bytes (54.4%); full public state and ledger audit remain unchanged. Timing samples are retained in evidence, but concurrent regression load makes them unsuitable for a speed claim. No Windows performance acceptance is inferred. Older binaries do not understand the new internal diagnostic encoding: preserve the original directory and test the new package in its own clean unpack; do not open a converted test database with an older executable.
