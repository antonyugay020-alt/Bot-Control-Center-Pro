# PR #12 isolated vertical recovery checks — NOT RELEASE

Baseline `5faf30369f3414f6e22d1d788d6f40426f4d10c9`; previous results and exact scope are in `PR12_INTEGRATION_REVIEW_20261118.md`. Existing risk controls remain enabled. No running user bot, account, external database or process is accessed.

A new reproducible, offline scenario (`tools/soak_pr12_ws_hub_worker.py`; `PYTHONPATH=.:tests python tools/soak_pr12_ws_hub_worker.py`) creates its own temporary Hub cache and PAPER ledger. It clears inherited Hub environment variables and rejects unexpected client HTTP. Synthetic Bybit ticker and depth frames enter the actual generation-fenced WS stream implementations, then the actual Hub leader/subscription and SQLite publication, real `PublicData` client, `process_tick`, VELES, risk model and PAPER ledger. It exercises 824 distinct symbols with six existing PAPER positions. A disconnected old WS generation is rejected; a stale executable book cannot trade. After reconnect, intentionally expired risk-tier evidence blocks a candidate entry, and freshly obtained synthetic tier/mark/depth evidence permits an entry in the same process. The sustained loop drives fresh synthetic events across all 824 symbols for 120 seconds and audits the ledger.

The same isolated session additionally feeds mocked HTTP 429 and 403 responses through real shared provider-policy machinery: the 429 prevents new HTTP admission while independently fresh WS reads remain available; the 403 denies client reads/publications and produces no fill. To model an eventually lifted provider restriction without waiting for a real external provider, its deadlines are expired *only inside the throwaway SQLite cache and process*, then newly ingested synthetic frames permit another PAPER entry. This is deliberately not a recommendation to bypass a real provider denial, and no real policy fence is altered.

Limitations: ticker, orderbook, history, risk responses and exchange signals are synthetic; these checks do not demonstrate actual recovery of a particular exchange outage. The scheduler's full-universe path is covered separately and is not integrated into this direct-worker WS loop. No real 824-symbol feed or native Windows Qt E2E has yet been executed at this source version. Real public Bybit 10-symbol/24-round transport evidence remains tied to baseline `70b3623`, as documented previously. Windows automated checks, all required manual PAPER scenarios and independent final review remain required; do not merge or release.
