# BCC V39 PAPER Desktop

Базовый коммит `f79fa8958651a7cace578518d31afb3b6dfc27b4`.

В Windows распакуйте архив в новую папку и откройте `START_PAPER.bat`.
Он вызывает обычный Qt-запуск и использует соседнюю папку `BCC_V39_PAPER_DATA`.
При первом запуске установленный Python создаёт локальную `.venv`
и устанавливает зависимости из `requirements.txt`.

Из чистой распаковки на Linux с Qt offscreen проверены `launch.pyw`,
видимость главного окна, готовность отдельной службы и её повторное
использование для того же профиля. Тесты запуска, Qt-управления PAPER-ботом
и WS-профиля дали 69 PASS. Для Windows по-прежнему требуется нативный запуск
этой сборки.

Windows V39 остановилась на первом WS-прогоне. В повторе с трассировкой
на Linux все восемь отказов совпали с отсутствием входящих ticker-кадров
AUSDT или 4USDT на обоих соединениях в интервале запроса. Принятые свежие
кадры дошли до SQLite. Точечная переподписка резервного канала проверялась
отдельно и не вошла в сборку. Ограничения свежести и профиль WS сохранены.
