## Факты о моделях и тарифах

Источники: рассылка Kie.ai от 10.11.2026, предоставленная пользователем,
и его снимки Kie.ai Pricing от 17.11.2026.

| \`terra\` | GPT-6.1 Terra | $0.30* | $0.015* | $1.50* |

*Из рассылки Kie.ai, указанные тарифы не проверены живым API.
Кэширование Terra: запись $0.375 / 1M по рассылке.
Тарифы Astra на Kie.ai Pricing начинаются с «от»: они могут не
соответствовать конкретному виду токенов, режиму или тарифу пользователя.

Важно: наличие строки \`gpt-6-astra\` в Kie.ai Pricing **НЕ**
доказывает, что через Kie.ai доступна та же модель, что Astra Pro
в интерфейсе ChatGPT. Не подставляйте название/слаг страницы как
подтверждённый API model ID или URL.

Нельзя назначить Astra по цене «от»: это **не максимальная цена**,
не подтверждение списания и не основание для допуска запроса.

## Архитектурная реализация

\`tools/bcc_kie_models.py\`: независимый от Claude модуль выбора моделей,
оценки затрат по известным категориям токенов, проверки синтетических
OpenAI Responses-shaped ответов и вычисления SHA-256 задания без вывода
его текста. Все поля API endpoint/model ID отсутствуют до проверки
на соответствующей странице **API**, и \`send_paid_request\` намеренно
всегда отклоняет вызов. Не импортирует сетевой клиент и не читает ключ.

Модель всегда задаётся ЯВНО. НЕТ автоматического fallback и платных
переключений между Terra, Kimi и Astra. Нет исполнения инструментов
на ПК. Ответы с незнакомым составом токенов, tool calls, неполным
состоянием или превышением лимитов отклоняются; в таком случае
бюджет нельзя автоматически считать израсходованным или возвращённым.

Пример бесплатной локальной диагностики в уже существующей
изолированной папке BCC_AGENT_GATEWAY:

    py -3 -I tools\bcc_kie_models.py
    py -3 -B -m unittest tests.test_bcc_kie_models -v

Это **не** проверка API Kie.ai и **не** тест запуска автономного
разработчика. Полный набор офлайн-тестов, включая ранее существующие
проверки Claude, включён в \`BCC_KIE_AGENT_CHECK.cmd\`.

## Политика расходов

Предыдущая единственная авторизация на Claude была израсходована
17.11.2026 (HTTP 502). Поддержка Kie.ai письменно сообщила о
недоступности Claude на неопределённый срок. Провайдер в журнале
показал 0 использованных кредитов; старый локальный резерв $0.01
остаётся нереконсилированным.

Других авторизаций пока НЕТ. Общий лимит по соглашению: $20/месяц,
допуск $18, резерв $2. Эти суммы **не являются** автоматическим
разрешением потратить деньги. Пока не подтверждены цены, настоящий
API-контракт, идентификатор модели, защищённое согласие на каждый
конкретный запрос и строгий общий бюджет для всех моделей —
платная передача отключена.

OpenAI API можно будет подключить отдельно, но **только после
явного подтверждения затрат**; ключи туда и из Windows Credential
Manager нельзя переносить в GitHub или чат.

## Следующие зависимости

1. Получить вкладку API на страницах моделей:
   https://kie.ai/gpt-6-1-terra и https://kie.ai/kimi-k3-1-pro;
   для Astra — точную страницу модели, которая открывается по строке
   \`gpt-6-astra\` в каталоге. Не передавать секреты.
2. Подтвердить model ID, URL, обязательные поля, отказ/ошибку, schema
   \`usage\`, доступность инструментария, лимиты запросов и тарифы.
3. Объединить **проверенный** денежный reserve с одним общим журналом
   Kie.ai, учитывая уже существующий Claude HOLD; не создавать
   независимую корзину расходов.
4. Только после отдельного пользовательского разрешения —
   короткий, строго ограниченный платный тест каждой выбранной модели
   с ручной сверкой биллинга. Никаких автоматических повторов при 502.
5. Нативная Windows Qt E2E BCC и архитектурные дефекты остаются
   отдельными release-gates; этот модуль сам по себе не завершает BCC.
