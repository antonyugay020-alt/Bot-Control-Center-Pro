## Coordinated fixes

- Before executing a queued Bybit tick, the owner can read current **genuine WS depth50** from the already admitted shared cache and combine it with that tick's previously validated instrument metadata. This uses a read-only cache lookup, never GET/subscription/network wait. The adapter tags the validated instrument symbol. Wrong source/symbol, provider denial, old exchange timestamps, missing or invalid depth, crossed/unsorted levels and nonfinite values cannot repair a handoff. Original depth time, update ID and sequence come from the cached exchange packet; risk metadata/timestamps and quantity filters are preserved. If no qualified cache book exists, the existing bounded asynchronous repair/failure policy remains. No quote is converted into execution depth or markPrice, and no timestamp/freshness gate is relaxed.
- PublicData rejects nonzero Bybit business responses **before successful cache publication**. Codes 10006/10018 record shared HTTP cooldown; HTTP 418/429 use the same observed-cooldown path. Retry-After and Bybit server/reset-time hints are finite and bounded. The real rate refusal remains fleet-wide even if its old request lease expired or was replaced; it cannot delete the successor's lease.
- Error payloads from an older producer cannot become fresh data through scalar/cohort reads or successful cache completion. They remain replaceable with genuine successful data. Non-rate business errors do not impose a host-wide cooldown on unrelated symbols. Rate feedback blocks new HTTP, while independent authentic WS publications and fresh cache rows remain usable. HTTP 403/451 remain the separate hard provider-denial fence.
- Report staging now uses the explicit mutable REPORTS tree when the destination is within the source tree, preserving same-volume atomic replacement. REPORTS and the three known root-level generated report ZIP prefixes are excluded from immutable source inventory; arbitrary similarly named Python files still fail verification. Repeated exports verify the source and do not include older report archives. REPORTS is git-ignored. The GUI suggests the selected runtime root's REPORTS directory instead of the process working directory. No broad `.bcc-*` source exclusion was introduced.

The quote/mark observer remains on the sole financial owner; cache execution recovery introduces no auxiliary financial writer and no extra fill by itself. Existing strategy, funding, shared risk, Stop/Restart and manual-exit tests remain enabled.
