# Единая Windows PAPER-приёмка Bybit

Это исходный QA-пакет, а не принятый релиз. Работайте только с новой полной распаковкой в отдельную локальную папку. Не копируйте туда MY_BOTS, SQLite или настройки других установок. Нужны интернет, Python 3.12 x64 (рекомендуется) и Git for Windows для полной проверки процессов.

1. Запустите `CHECK_BYBIT_WINDOWS.bat`. Он создаст отдельное Python-окружение, установит зависимости и проверит SHA-256 до и после этапов. Перезагрузка Windows не нужна.
2. Автоматически выполняются полная регрессия, нативные Qt-проверки, 24 раунда по восьми монетам публичного Bybit WS (192 чтения стакана и независимого markPrice), а также проверка необходимых публичных REST-данных Bybit. ADAUSDT обязательна в каждом раунде. Пропущенный markPrice, устаревшие данные, задержки или незавершённое выключение своего Hub блокируют PASS. Другие торговые площадки этим запуском не сертифицируются.
3. Только после успешных автоматических этапов откроется PAPER-приложение в пустом отдельном рабочем каталоге. Проверьте VELES, GRID и Pump & Dump: создание и редактирование, вход/выход по реальным условиям, DCA там, где настроен, комиссии, PnL, маржу, историю, мониторинг, Stop/Restart. Закрытие и повторное открытие окна должно сохранять счёт и позиции. Отсутствие сигнала входа само по себе не является успешной проверкой торгового цикла.
4. Для проверки восстановления кратко отключите сеть: устаревшие оценки должны исчезнуть, сделки блокироваться; после восстановления нужны новые настоящие данные. Нельзя сохранять прежний PnL как свежий или заменять markPrice ценой bid/ask. Не останавливайте процессы других установок.
5. Запишите выполненные сценарии и ошибки в `OBSERVATIONS.txt` проверочного отчёта. Закройте проверочное окно и завершите предложенный цикл. Скрипт остановит только принадлежащие его новому каталогу процессы и создаст `BCC_VALIDATION_RESULTS_*.zip` рядом с запуском. Передайте этот архив для проверки результатов.

HTTP 403/451 публичного REST — блокер данных, даже если WS доступен. Не обходите отказ и не включайте реальные ордера. Надпись «нет свежей оценки» при остановленном worker, обрыве или отсутствии достоверной котировки остаётся правильной.

Автоматический PASS не подтверждает ручные торговые циклы и независимую приёмку. До их подтверждения не объединять PR и не выпускать релиз. Обычный `CHECK_WINDOWS.bat` по-прежнему запускает проверку всех площадок.
