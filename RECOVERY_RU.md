# Перенос сохранённого PAPER-бота в пакет 11

В прежней оболочке остановите выбранного бота и сохраните полный экспорт:
«Перенос → Экспорт выбранного бота» → «Настройки, баланс, позиции, статистика
и журналы». Храните ZIP отдельно от программы.

Распакуйте новую сборку в отдельную папку. В новом окне выберите
«Перенос → Импорт независимых копий», затем полный состав данных.
Импорт не запускает бота. Проверьте баланс, позиции и историю, затем запускайте
новую копию. Прежняя копия должна оставаться остановленной. Старую папку сохраните.

CHECK_WINDOWS.bat создаёт отдельный корень внутри check_workspaces/<дата-время>.
START.bat открывает обычную папку приложения. Для получения диагностики существующих
ботов нажмите «Сохранить отчёт» и при необходимости выберите именно прежний корень,
содержащий MY_BOTS. Эта выгрузка не переносит ботов и не останавливает процессы.

Не заменяйте актуальный счёт данными из старого проверочного отчёта.
Не удаляйте paper.sqlite или MY_BOTS для устранения проблем публичного кэша.
При миграции графиков внутри SQLite сохраняются баланс, позиции, история и
ожидающие закрытия. Старый движок не следует запускать на обновлённой папке данных.

Новые исполнения содержат исходную метку стакана и границы его возраста.
Для перенесённой старой истории они не подставляются: отчёт отдельно указывает
число исполнений без сохранённого доказательства свежести.
